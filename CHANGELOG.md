# Changes

## Unreleased

### Call Copilot preview

- Added consistent status colors with text and icons, topic summaries and linked decisions. Personal to-dos remain actionable until marked done; discussed topics are not automatically presented as completed work.

- Follow a bilingual call with local transcription for your microphone and the Mac's audio.
- Review suggested agreements, agent tasks and personal to-dos. Approve agent work in T3 Code while the call continues.
- Use separate Overview, Decisions, Topics, Transcript and Details views. Opening a view replaces the content area; Escape keeps the selected view.
- Open topics and decisions with consistent whole-row disclosures. Larger text and wider records make the saved call easier to read.
- Keep the current live decision pinned when new ones arrive. Changing titles, counts and processing states use reserved layout space.
- Press T to write a task, note or personal to-do. Search and correct transcript lines, or turn a line into a task.
- Preview summary text before copying. Review the effect of memory recording, follow-up drafting and decision-list agent actions before starting them.
- Return to saved calls through History, search across calls, and review commitments in Outcomes.

### Setup and verification

- Expanded README: installation, first-call walkthrough, action meanings, privacy, manual updates and troubleshooting.
- Added a dependency-free, read-only Chrome UI check with optional screenshots. It blocks API writes and replays live updates inside the browser.
- Added an explicit release-check list for capture, service failures, recovery and updates. These scenarios are not all automated yet.

### Before trying it

Call Copilot requires additional tools beyond dictation: Node, an analysis provider, and T3 Code for agent work. Automatic recap is enabled by default and can start an agent that writes workspace memory. Turn it off in Settings for manual-only recording.

This is an unreleased source-checkout preview, not a packaged release announcement. Updates remain manual. See the [README](README.md) for setup and current limits.
